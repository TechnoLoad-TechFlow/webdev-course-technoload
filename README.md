# Curso Introductorio de Desarrollo Web: HTML y CSS desde Cero

Repositorio oficial de materiales, archivos base, ejemplos resueltos y guiones para el curso en video de desarrollo web dirigido a estudiantes de secundaria (12 a 17 años) sin experiencia previa en programación.

## Herramienta en línea seleccionada

Para garantizar que los estudiantes puedan aprender **sin instalar ningún programa ni crear cuentas obligatorias**, este curso utiliza **[JSFiddle](https://jsfiddle.net/)** como editor principal en línea:

- **100 % en línea y gratuito**: Funciona directamente desde cualquier navegador web moderno (Chrome, Firefox, Safari, Edge).
- **Sin registro obligatorio**: Los estudiantes pueden abrir un enlace precargado, editar el código y ver los resultados al instante sin iniciar sesión.
- **Interfaz clara para principiantes**: Separa visualmente el código **HTML**, el código **CSS** y el panel de **Result** (vista previa en vivo).
- **Alternativa compatible**: Todos los ejemplos también funcionan sin cambios en [PlayCode](https://playcode.io/html).

## Instrucciones de configuración

### Para estudiantes del curso
1. Abre tu navegador web preferido (Chrome, Firefox, Safari o Edge).
2. Haz clic en el enlace de JSFiddle incluido en la descripción de cada video de YouTube (o copia el contenido de `starter-files/lesson-XX/` en [jsfiddle.net](https://jsfiddle.net/)).
3. Presiona **Run** (o `Ctrl + Enter` / `Cmd + Enter`) para ver los cambios en tiempo real.

### Para el equipo de producción (4 estudiantes)
1. Lee la guía [scripts/GUIA-GRABACION-4-ESTUDIANTES.md](scripts/GUIA-GRABACION-4-ESTUDIANTES.md) para ver el reparto equitativo de las 10 lecciones, estándares de audio/video y pasos de edición.
2. Antes de grabar cada lección, crea el Fiddle precargado en [jsfiddle.net](https://jsfiddle.net/) copiando los archivos de `starter-files/lesson-XX/`, guarda la URL pública y colócala en la descripción del video y en `course-plan.md`.
3. Sube los videos a YouTube como **No listados** (*Unlisted*), sin marcas personales ni referencias a los autores dentro del video ni del código fuente.
4. Actualiza `course-plan.md` con los enlaces reales de YouTube, JSFiddle y los datos de entrega, y expórtalo a PDF siguiendo la nomenclatura del curso (`upc-pre-202620-1asi0730-<NRC>-<startup>-course-plan.pdf`).
