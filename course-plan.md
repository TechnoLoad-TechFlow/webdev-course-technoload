# Fundamentos de Desarrollo Web

## Resumen del Curso

Este curso de 50 minutos (10 lecciones de 5 minutos) introduce a estudiantes de secundaria a la creación de sitios web sencillos con HTML y CSS. **¡No requiere descargas ni registro!** Solo abre tu navegador web.

- **Duración total**: 50 minutos (10 lecciones cortas de 5 minutos cada una)
- **Público objetivo**: Estudiantes de 12 a 17 años sin experiencia previa en programación
- **Prerrequisitos**: Ninguno
- **Herramienta en línea**: [JSFiddle](https://jsfiddle.net/) — **¡Solo tu navegador web!** (Chrome, Firefox, Safari, Edge)
- **📂 Repositorio de código fuente**: [https://github.com/TechnoLoad-TechFlow/webdev-course-technoload](https://github.com/TechnoLoad-TechFlow/webdev-course-technoload)

## Secuencia de la lección

### Lección 1: ¿Qué es el desarrollo web? Tu primer vistazo a JSFiddle (5 minutos)
- **Descripción**: Aprende qué es un sitio web, cómo trabajan juntos HTML y CSS en la vida real y explora el editor en línea JSFiddle sin instalar nada.
- **Enlace**: [Ver la lección](https://www.youtube.com/watch?v=REEMPLAZAR-LECCION-1)
- **Consejos clave**: Sitio web = Estructura/Contenido (HTML) + Diseño/Estilo (CSS).
- **Empieza a programar**: [Abrir práctica en JSFiddle](https://jsfiddle.net/REEMPLAZAR-LECCION-1) 👈 **¡No necesitas registrarte!**

### Lección 2: Tu primera página HTML: etiquetas y estructura básica (5 minutos)
- **Descripción**: Descubre qué son las etiquetas de apertura y cierre, y crea tus primeros encabezados y párrafos en HTML.
- **Enlace**: [Ver la lección](https://www.youtube.com/watch?v=REEMPLAZAR-LECCION-2)
- **Consejos clave**: Usa `<h1>` a `<h3>` para títulos y `<p>` para párrafos; recuerda siempre cerrar tus etiquetas (`</p>`).
- **Práctica**: [Clic para programar en JSFiddle](https://jsfiddle.net/REEMPLAZAR-LECCION-2) 👈 **¡Comienza al instante!**

### Lección 3: Atributos y enlaces: conectando páginas web (5 minutos)
- **Descripción**: Aprende qué es un atributo HTML y cómo crear enlaces interactivos que lleven a otros sitios web usando la etiqueta `<a>`.
- **Enlace**: [Ver la lección](https://www.youtube.com/watch?v=REEMPLAZAR-LECCION-3)
- **Consejos clave**: Usa `href="https://..."` dentro de `<a>` y `target="_blank"` para abrir en una nueva pestaña.
- **Práctica**: [Clic para programar en JSFiddle](https://jsfiddle.net/REEMPLAZAR-LECCION-3) 👈 **¡Comienza al instante!**

### Lección 4: Imágenes y listas: páginas más visuales y ordenadas (5 minutos)
- **Descripción**: Agrega fotografías con `<img>` y organiza tus pasatiempos o pasos favoritos usando listas con viñetas (`<ul>`) y listas numeradas (`<ol>`).
- **Enlace**: [Ver la lección](https://www.youtube.com/watch?v=REEMPLAZAR-LECCION-4)
- **Consejos clave**: La etiqueta `<img>` usa `src` para la ruta y `alt` para describir la imagen; cada elemento de lista va dentro de `<li>`.
- **Práctica**: [Clic para programar en JSFiddle](https://jsfiddle.net/REEMPLAZAR-LECCION-4) 👈 **¡Comienza al instante!**

### Lección 5: Introducción a CSS: selectores y reglas de estilo (5 minutos)
- **Descripción**: Da el salto al diseño web entendiendo qué es CSS, cómo se escribe una regla y cómo seleccionar elementos HTML para transformarlos.
- **Enlace**: [Ver la lección](https://www.youtube.com/watch?v=REEMPLAZAR-LECCION-5)
- **Consejos clave**: Una regla CSS tiene un selector, llaves `{ }` y pares `propiedad: valor;`.
- **Práctica**: [Clic para programar en JSFiddle](https://jsfiddle.net/REEMPLAZAR-LECCION-5) 👈 **¡No necesitas registrarte!**

### Lección 6: Colores y tipografía: personalidad para tu sitio web (5 minutos)
- **Descripción**: Cambia colores de texto, fondos y tipos de letra para que tu página refleje tu estilo personal y sea fácil de leer.
- **Enlace**: [Ver la lección](https://www.youtube.com/watch?v=REEMPLAZAR-LECCION-6)
- **Consejos clave**: Usa `color`, `background-color`, `font-family` y `font-size` manteniendo buen contraste.
- **Práctica**: [Clic para programar en JSFiddle](https://jsfiddle.net/REEMPLAZAR-LECCION-6) 👈 **¡Comienza al instante!**

### Lección 7: Espaciado, bordes y centrado: diseño limpio en CSS (5 minutos)
- **Descripción**: Aprende a centrar contenido, añadir bordes redondeados y dar aire alrededor de tus elementos con `padding` y `margin`.
- **Enlace**: [Ver la lección](https://www.youtube.com/watch?v=REEMPLAZAR-LECCION-7)
- **Consejos clave**: `padding` es el espacio interno, `margin` es el espacio externo y `text-align: center` centra texto e imágenes.
- **Práctica**: [Clic para programar en JSFiddle](https://jsfiddle.net/REEMPLAZAR-LECCION-7) 👈 **¡Comienza al instante!**

### Lección 8: Proyecto Final (Parte 1): Estructura HTML de tu página de perfil (5 minutos)
- **Descripción**: Construye desde cero la estructura HTML de una página de perfil personal con foto, biografía, lista de intereses y enlaces.
- **Enlace**: [Ver la lección](https://www.youtube.com/watch?v=REEMPLAZAR-LECCION-8)
- **Consejos clave**: Organiza tu contenido dentro de contenedores `<div>` o `<section>` con clases claras (`class="tarjeta"`).
- **Práctica**: [Clic para programar en JSFiddle](https://jsfiddle.net/REEMPLAZAR-LECCION-8) 👈 **¡Proyecto en progreso!**

### Lección 9: Proyecto Final (Parte 2): Estilizando tu página de perfil con CSS (5 minutos)
- **Descripción**: Convierte el HTML de la lección anterior en una tarjeta de perfil moderna con fondo suave, foto circular, sombras y botones llamativos.
- **Enlace**: [Ver la lección](https://www.youtube.com/watch?v=REEMPLAZAR-LECCION-9)
- **Consejos clave**: Usa `border-radius: 50%` para fotos circulares y `margin: 40px auto` para centrar la tarjeta.
- **Proyecto Final**: [Completa tu Perfil en JSFiddle](https://jsfiddle.net/REEMPLAZAR-LECCION-9) 👈 **¡Guarda y comparte!**

### Lección 10: Errores comunes, recomendaciones y próximos pasos (5 minutos)
- **Descripción**: Repasa los 5 errores más frecuentes al empezar con HTML y CSS, aprende a corregirlos rápido y descubre dónde seguir practicando gratis.
- **Enlace**: [Ver la lección](https://www.youtube.com/watch?v=REEMPLAZAR-LECCION-10)
- **Consejos clave**: Revisa etiquetas sin cerrar, puntos y comas olvidados en CSS y explora la Documentación Web de MDN.
